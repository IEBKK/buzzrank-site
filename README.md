# buzzrank-site

BuzzRank 랭킹 페이지의 **발행본**입니다. 이 리포지토리의 파일은 전부 생성물이고,
사람이 직접 고치지 않습니다 — 다음 배포가 덮어씁니다.

소스는 비공개 리포지토리에 있습니다. 이 저장소가 따로 존재하는 이유는 하나입니다:
GitHub Pages 를 무료로 쓰려면 공개 저장소여야 하는데, 수집 아카이브
(`data/archive/news_mentions.jsonl`)는 RSS 로 소급 수집이 불가능해 한 번 놓치면
복구되지 않는 시계열이라 공개 대상이 아닙니다.

- 페이지: https://iebkk.github.io/buzzrank-site/
- 갱신: 매일 00:30 KST, 비공개 리포지토리의 `pages` 워크플로가 푸시합니다.
- 산정 방법과 정확도 실측치는 페이지의 **방법론** 탭에 있습니다.
